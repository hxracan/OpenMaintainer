# Roadmap

This is a direction, not a release promise.

## Validate with real maintainers

- Run a staging GitHub App against consenting test repositories.
- Measure usefulness and false positives; publish reproducible benchmarks only after measurement.
- Complete independent security review before encouraging high-trust deployments.

## Deepen analysis

- Cross-file TypeScript API resolution and Python/Go/Rust API compatibility checks.
- Semantic duplicate ranking with labeled evaluation sets.
- Dependency registry freshness and reliable maintainer-response/review metrics.
- Incremental remote content caching beyond fingerprint reuse and per-client ETags.

## Operational maturity

- Operator UI for ambiguous-action reconciliation and dead-job retries.
- OAuth refresh tokens and explicit organization-role administration.
- Multi-worker load/chaos testing, stronger per-installation budgets and migration checksums.
- Plugin process/container sandboxing; declarative plugin conditions/actions in rules.
- Accessibility audit, richer automation builder and release comparison UI.

No adoption, contributors, user numbers or application outcomes are implied by this roadmap.
