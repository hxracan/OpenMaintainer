# Code of conduct

Treat contributors with respect. Welcome questions and constructive disagreement. Do not harass, threaten, discriminate, publish private information, impersonate others or manipulate project engagement.

Keep reviews about code and evidence, not personal attacks. Respect confidentiality and give credit accurately.

The repository owner may edit or remove harmful content, limit participation, or block accounts when needed to protect contributors. Reports can be sent privately through a channel the owner makes available on their GitHub profile. Do not post private evidence publicly. Decisions should be proportionate and conflicts of interest disclosed.
