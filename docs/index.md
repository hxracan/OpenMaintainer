# OpenMaintainer documentation

Start with the [installation guide](installation.md). For a credential-free introduction, run `pnpm demo` from the checkout and visit localhost:3000.

OpenMaintainer is a self-hosted assistant to maintainer judgment, not an autonomous merge or release bot. Deterministic engines produce findings; approved policies determine permitted actions. AI is optional and advisory.
